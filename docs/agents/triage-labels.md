# Triage Labels

Mapping des cinq rôles canoniques aux labels utilisés dans ce projet.

| Label canonique     | Notre label         | Signification                                          |
| ------------------- | ------------------- | ------------------------------------------------------ |
| `needs-triage`      | `needs-triage`      | Maintainer doit évaluer cette issue                    |
| `needs-info`        | `needs-info`        | En attente d'info du reporter                          |
| `ready-for-agent`   | `ready-for-agent`   | Entièrement spécifié, prêt pour un agent AFK           |
| `ready-for-human`   | `ready-for-human`   | Nécessite implémentation humaine                       |
| `wontfix`           | `wontfix`           | Ne sera pas traité                                     |

Pour les issues locales markdown, applique le label comme ligne `Status: <label>` près du haut du fichier.
